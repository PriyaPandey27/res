# Priya Pandey — Portfolio

A modern, responsive portfolio website showcasing AI engineering, Multimodal RAG pipelines, and full-stack software development. Built with React, Vite, Framer Motion, and Lucide React.

## Featured Projects

- **[Auditra](https://github.com/PriyaPandey27/Auditra)** — Autonomous AI Finance Controller & 7-stage deterministic reconciliation pipeline.
- **[DocuVision AI](https://github.com/PriyaPandey27/DocuVision-AI)** — Multimodal RAG document assistant with HuggingFace Gemma-2B & Annoy vector search.
- **[Local Enterprise RAG](https://github.com/PriyaPandey27/local-enterprise-rag)** — Hybrid retrieval (FAISS + BM25) zero-leakage RAG pipeline with local LLMs.
- **[FIRST_CALL](https://github.com/PriyaPandey27/FIRST_CALL)** — AI-powered healthcare assistant for disease prediction & emergency pharmacy discovery.
- **[CineMatch](https://github.com/PriyaPandey27/CineMatch)** — Semantic movie discovery engine utilizing NLP & plot similarity embeddings.
- **[NexusBlog](https://github.com/PriyaPandey27/NexusBlog)** — Full-stack publishing platform with AI drafting assistance.

## Run Locally

```bash
npm install
npm run dev
```

Open the local development URL provided by Vite.

## Build for Production

```bash
npm run build
npm run preview
```
